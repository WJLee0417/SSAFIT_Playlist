## 별도 명세가 필요한 예외 흐름

- Spotify OAuth: redirect URI 불일치, state 불일치, 사용자 동의 거부, token 만료/갱신 실패.
- Spotify 내보내기: Spotify Playlist 생성 성공 후 수록곡 추가 실패가 발생하는 부분 실패 상태.
- 러닝 세션 참여: CLOSED/CANCELLED 상태, 정원 초과, 중복 참여, 작성자 권한 예외.
- 추천: 러닝 프로필 또는 최근 기록 부족으로 인한 fallback/데이터 부족 처리.
- JSP/Vue 혼합 인증: JSP 로그인 후 Vue 보호 라우트로 복귀하는 경로와 실패 시 `/login-required`, `/access-check-failed` 이동.
